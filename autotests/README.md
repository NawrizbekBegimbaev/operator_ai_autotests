# Автотесты Operator AI

## TC-001

Первый автоматизированный кейс проверяет вход супер-админа через UI:

- успешную авторизацию;
- точный редирект на `/dashboard/rop`;
- загрузку таблицы компаний РОП;
- пункты меню «РОПы», «Лиды», «Тарифы».

Тест самого входа намеренно использует чистый браузный контекст. Общий
`storage_state` будет применяться к функциональным UI-тестам, но не к кейсам
авторизации, выхода и refresh.

## Подготовка

1. Создать виртуальное окружение и установить `requirements.txt`.
2. Установить Chromium командой `python -m playwright install chromium`.
3. Скопировать имена переменных из `.env.example` в локальный `.env`.
4. Заполнить URL staging/test и учётные данные супер-админа.

Production блокируется значением `OPERATOR_AI_TARGET_ENV`: разрешены только
`staging` и `test`. URL по умолчанию отсутствует.

## Запуск

```powershell
python -m pytest autotests/tests/web/auth/test_tc_001_superadmin_login.py
```

Headless-режим включён по умолчанию. Trace и screenshot сохраняются только
при падении.
