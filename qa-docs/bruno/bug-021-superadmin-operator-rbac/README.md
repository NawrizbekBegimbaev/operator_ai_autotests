# Ручная проверка BUG-021 в Bruno

Коллекция проверяет, может ли Super-admin изменить через API временного
оператора, принадлежащего РОП.

## Безопасность

- Выполняйте запросы только на staging/test, никогда на production.
- API base URL хранится только в локальном `.env`, который исключён из Git.
- Bruno запросит только учётные данные во всплывающих окнах.
- Используется новый временный оператор с префиксом `AT-BRU-`.
- После проверки обязательно выполните запрос `07 — Удалить временного оператора`.
- Не публикуйте request/response с заголовком `Authorization`.

## Как открыть

1. В Bruno выберите **Open Collection**.
2. Укажите папку `qa-docs/bruno/bug-021-superadmin-operator-rbac`.
3. Не используйте Collection Runner: интерактивные prompt-переменные в нём
   пропускаются.
4. Запускайте запросы вручную строго по порядку от `01` до `07`.

Все запросы автоматически используют переменную
`OPERATOR_AI_API_BASE_URL` из локального `.env` коллекции. Вводить URL при
запуске `01` больше не нужно.

## Как принять решение

Решающие запросы — `05` и `06`.

- **Не баг:** `05` возвращает HTTP 403 с `title=Forbidden` и
  `detail="ruxsat yo'q"`; `06` показывает полностью неизменённую запись.
- **Баг подтверждён:** `05` возвращает HTTP 200 и `06` показывает новое
  значение `first_name`, начинающееся с `AT-BRU-AFTER-`.

Красные тесты у запросов `05` и `06` при HTTP 200 означают воспроизведение
BUG-021, а не поломку коллекции. Независимо от результата выполните `07`.
