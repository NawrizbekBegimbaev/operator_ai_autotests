## Два кейса, заблокированные BUG-045

Первичные сообщения двух тестов выглядели как отсутствие данных, однако
дополнительная проверка API показала, что нужные записи на staging существуют.
Они скрываются при запросе первой страницы с `perPage=6`, который использует
карточка оператора.

### TC-060 — детали выбранного звонка

- Ожидание: после выбора звонка открываются данные именно этого звонка.
- Фактический результат: UI-запрос первой страницы с `perPage=6` возвращает
  пустой список, хотя при `perPage=30` и `perPage=100` для того же оператора
  возвращаются звонки, включая событие без `deal_id`.
- Классификация: кейс не дошёл до проверки BUG-027 из-за подтверждённого
  BUG-045.
- Вывод по BUG-027: нельзя подтвердить ни воспроизведение, ни исправление.

Точное сообщение:

```text
[TC-060 call-details setup] среди последних звонков нет события без deal_id для воспроизведения BUG-027
```

### TC-370 — воспроизведение аудио в карточке оператора

- Ожидание: Play запускает запись и продвигает время, повторное нажатие ставит
  запись на паузу.
- Фактический результат: UI-запрос первой страницы с `perPage=6` возвращает
  пустой список, хотя расширенный запрос на staging находит 12 звонков с
  HTTP(S)-адресами аудио.
- Классификация: кейс не дошёл до проверки BUG-026 из-за подтверждённого
  BUG-045.
- Вывод по BUG-026: нельзя подтвердить ни воспроизведение, ни исправление.

Точное сообщение:

```text
[TC-370 setup] в последних звонках операторов нет HTTP(S)-аудио
```

### Подтверждённая причина

Backend сначала применяет SQL `LIMIT/OFFSET`, затем фильтрует уже выбранную
страницу по телефонам назначенной воронки и после этого заменяет `totalItems`
числом оставшихся элементов. Поэтому состав первой страницы и метаданные
пагинации зависят от `perPage`: существующие звонки могут полностью исчезнуть
из ответа и из карточки оператора.

Дефект зарегистрирован как BUG-045. После полного прогона добавлена отдельная
read-only регрессионная проверка согласованности первой страницы при
`perPage=6`, `30` и `100`. Она не входит в приведённые выше 178 результатов:
после добавления коллекция содержит 179 тестов, а её отдельный запуск ожидаемо
завершился как `1 xfailed` по BUG-045.
